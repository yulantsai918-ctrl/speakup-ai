核心 API 整合：

整合 Gemini 2.5 Flash API，扮演您的專屬外籍英語教練。

實作文法與道地度分析：當您在角色扮演（Roleplay）中講完一句話，Gemini 會以 JSON 格式回傳您說的內容，並自動為您生成「文法修正意見」以及「更道地的三種美式講法（Polished Version）」。

Web Speech API（語音辨識與朗讀）：

使用瀏覽器內建的 SpeechRecognition 進行語音輸入，免去複雜的第三方語音轉文字設定，點擊麥克風即可開始口說。

使用 SpeechSynthesis 進行流暢的 AI 語音回覆播放，讓您同時訓練聽力與口說。

豐富的角色扮演場景與提示字卡 (Hints)：

提供「咖啡廳點餐」、「機場海關」、「科技業模擬面試」等真實情境。

提供「對話提示字卡（Hints）」，當您不知如何接話時，能一鍵參考推薦的講法。

精美科技感介面（Tailwind CSS）：

仿 Speak 的優雅介面，包括「流暢波形動畫」、「連續登入天數統計」、「等級與累積字數」，並提供即時的口說卡片評分（綠色表示完美、黃色表示有待加強、藍色代表更道地的講法）。
